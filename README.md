# cloudcad
Open-source 3D modeling software for creating geometry directly from point clouds.

<img width="960" height="495" alt="CloudCAD" src="https://github.com/user-attachments/assets/38f4cf6d-a291-4d76-bf99-d8ca16daf5a5" />


How to Install:                        
1. Make sure you have python installed and added to PATH                    
2. cd into the folder containing the code, and run the following commands:           
python -m pip install -r requirements.txt                            
python modeler.py
